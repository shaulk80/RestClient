KNOWN ISSUES AND NOTES
----------------------
- The release zips include .pdb files (about 100 MB uncompressed). Consider
  DebugType=none for release publishes; not changed yet.
- Startup errors (data folder cannot be created, migration fails) are written to
  stderr only. The Windows build is a GUI app with no console, so the user sees
  nothing. Replace with a visible error dialog before M1 ships anything users rely on.
- Integration and UI test projects are empty until M1 and M6. dotnet test reports
  "No test is available" for them but exits 0.
